# Bolsillo Producciones — Sitio Web

Sitio web estático para **Bolsillo Producciones SPA**, estudio de fotografía y video en Santiago de Chile. Publicado en [bolsilloprod.cl](https://bolsilloprod.cl) vía **GitHub Pages**.

## Estado actual: página en cuarentena

Mientras se rehace el sitio desde cero, `bolsilloprod.cl` muestra una sola página que redirige a la gente a Instagram ([@bolsilloprod](https://instagram.com/bolsilloprod)).

```
├── index.html   ← Landing única: fondo galaxia + aviso "volvemos pronto" + botón a Instagram
├── 404.html     ← Cualquier URL vieja (/fotografia, /audiovisual, /terminos…) redirige a la portada
└── nojekyll
```

## Sitio anterior (copia histórica)

El sitio completo anterior (index, fotografía, audiovisual y términos) quedó guardado en git:
